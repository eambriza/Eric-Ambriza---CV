# Brutalist CV - Eric Ambriza

A bold, typography-led one-page scrolling CV website inspired by brutalist web design principles.

## Design Features

### Typography-Led Design
- **Massive Display Typography**: Using the Mortend display font for impactful headers
- **Monospace Details**: BitBlox Monospaced for technical information and labels
- **Layered Text Effects**: Multiple text shadows creating depth and visual interest

### Brutalist Elements
- **Bold Color Palette**: Cyber blue (#00FFFF), hot pink (#FF00FF), neon green (#00FF00), electric yellow (#FFFF00)
- **Harsh Shadows**: 8px+ black shadows on all elements
- **Sharp Borders**: 4px+ black borders throughout
- **Raw Geometric Shapes**: Squares and rectangles as decorative elements

### Layout Structure
1. **Hero Section**: Full-screen name display with contact info in colored blocks
2. **Experience Section**: Timeline-style layout with bold company cards
3. **Skills Section**: Grid of categorized skill blocks
4. **Education & Certifications**: Side-by-side layout with rotated headers
5. **CTA Footer**: Large call-to-action buttons with hover effects

### Interactive Elements
- **Hover Animations**: Buttons translate and lose shadows on hover
- **Scroll Animations**: Framer Motion animations triggered on scroll
- **Responsive Design**: Mobile-optimized with smaller elements and adjusted typography

### Inspiration
Based on the Inkredible Notary website's approach to:
- Bold, unapologetic typography
- High contrast color schemes
- Geometric layout elements
- Raw, unpolished aesthetic

## Technical Implementation
- **Next.js 14** with App Router
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **TypeScript** for type safety
- **Responsive Design** with mobile-first approach

## Color System
- **Primary**: Matrix Black (#000000) and Screen White (#F0F0F0)
- **Accents**: Cyber Blue, Hot Pink, Neon Green, Electric Yellow
- **Shadows**: Always black for maximum contrast

The design embraces the "ugly" aesthetic of brutalism while maintaining readability and professional presentation of CV content.
