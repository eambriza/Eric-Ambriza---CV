# Section Color Harmony System

## Neo-Brutalist Color Palette Applied

### Color Definitions
- **Deep Navy**: #0F2E5A - Primary text and strong accents
- **Royal Blue**: #2D6AE3 - Hover states and connecting elements
- **Sky Blue**: #EAF4FF - Light backgrounds and cards
- **Mint**: #ECFFF7 - Fresh accent backgrounds
- **Teal**: #2EC4B6 - Primary accent color
- **Lime**: #7BD389 - Success states and highlights
- **Butter Yellow**: #FFF4C2 - Warm section backgrounds
- **Peach**: #FFE6D1 - Soft card backgrounds
- **Warm Orange**: #FFB86B - Call-to-action elements
- **Label Purple**: #6F5FF5 - Interactive elements and labels

## Visual Flow Strategy

### Recurring Accent Colors
1. **Teal (#2EC4B6)**: Appears in HOME → EXPERIENCE → SKILLS for continuity
2. **Label Purple (#6F5FF5)**: HOME → SKILLS → PORTFOLIO for creative thread
3. **Royal Blue (#2D6AE3)**: CONTACT hover states connecting back to HOME
4. **Mint (#ECFFF7)**: EXPERIENCE → SKILLS → CONTACT for freshness
5. **Peach (#FFE6D1)**: PORTFOLIO → EDUCATION for warm transition

### Border Strategy
- **Deep Navy**: Primary borders for strong definition
- **Section Colors**: Matching borders for cohesion
- **Accent Colors**: Thin accent borders for visual flow

### Text Contrast
- **Deep Navy text** on all light backgrounds for readability
- **White text** on Deep Navy and Label Purple backgrounds
- High contrast maintained throughout for accessibility

## Neo-Brutalist Principles Maintained
- **Flat Colors**: No gradients, pure color blocks
- **Bold Borders**: Strong 4px borders for definition
- **Sharp Shadows**: Brutal shadow effects preserved
- **High Contrast**: Clear text readability
- **Geometric Shapes**: Clean rectangular forms
- **Functional Design**: Colors serve navigation and hierarchy

This system creates distinct section personalities while maintaining visual unity through strategic color repetition and smooth transitions.
