## 🎨 NEW COHESIVE COLOR PALETTE

Based on the hero section, this palette ensures consistency across the entire website while maintaining a professional look.

### **Primary Colors:**

1. **Navy Blue (Background):** `#0F2A4A`
   - Use for: Main backgrounds, primary dark elements
   - Replaces: `#0f2e5a` (deep-navy)

2. **Cream/Off-White (Primary Text):** `#F5F0DC`
   - Use for: Headings, important text elements, light text on dark backgrounds
   - Replaces: `#FFF8DC` (text-cream), `#fff6ee` (light cream)

3. **Light Blue-Gray (Content Panels):** `#6D8CAE`
   - Use for: Information panels, content backgrounds, cards
   - Replaces: `#7EA3BD` (teal-accent)

### **Accent Colors:**

4. **Vibrant Orange:** `#FF7F27`
   - Use for: Call-to-action elements, highlights, important sections, 3D cube
   - Replaces: `#FF7A18` (warm-orange)
   - **PRIMARY ACCENT** - Use for emphasis and CTAs

5. **Light Purple:** `#B088E0`
   - Use for: Secondary sections like certifications, decorative elements
   - Replaces: `#8B5CF6` (label-purple)

6. **Soft Cream/Beige:** `#F8ECC2`
   - Use for: Education sections, background content areas, subtle highlights
   - Replaces: `#FFCBA4` (peach), `#F4E4BC` (butter-yellow)

### **Supporting Colors:**

7. **Lighter Blue:** `#8EABC8`
   - Use for: Skills sections, technical information, secondary highlights
   - Replaces: `#87CEEB` (sky-blue), `#DDEAF0` (light blue background)

8. **Dark Gray:** `#333333`
   - Use for: Secondary text, subtle elements
   - New addition for text hierarchy

9. **Light Gray:** `#E5E5E5`
   - Use for: Dividers, subtle elements, borders
   - New addition for UI elements

## 🎯 DESIGN PRINCIPLES

### Visual Hierarchy:
1. **Primary:** Navy Blue (#0F2A4A) - Foundation
2. **Accent:** Vibrant Orange (#FF7F27) - Attention
3. **Content:** Light Blue-Gray (#6D8CAE) - Information
4. **Text:** Cream (#F5F0DC) - Readability
5. **Secondary:** Light Purple (#B088E0) - Variety
6. **Soft:** Soft Cream (#F8ECC2) - Warmth

### Contrast Ratios:
- Navy Blue + Cream: High contrast (excellent readability)
- Light Blue-Gray + Cream: Good contrast
- Vibrant Orange + Navy Blue: High contrast (perfect for CTAs)
- Light Purple + Cream: Good contrast

### Accessibility:
- All text combinations meet WCAG AA standards
- High contrast for important elements
- Consistent color usage for similar elements
